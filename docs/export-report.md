# Knead data-pack export report

Every data-pack ZIP generated by Studio contains `knead-export-report.json`.
The report is deterministic: it contains no timestamp, paths or machine-local
state, and equal projects/options produce equal report bytes.

## Version 1

```json
{
  "schemaVersion": 1,
  "generator": "Knead Studio",
  "namespace": "knead_show",
  "targetVersion": "1.21.4",
  "summary": {
    "eventCount": 120,
    "skippedEventCount": 0,
    "durationTicks": 400
  },
  "diagnostics": [
    {
      "code": "command.tempo_map.baked",
      "severity": "info",
      "disposition": "baked",
      "feature": "timing",
      "message": "Tempo and meter changes are baked into Knead's fixed 20 TPS event positions."
    }
  ]
}
```

`code` is the stable identifier. `message` is deterministic English fallback
text and may be shown by tools that do not ship Knead's locale catalog.
`severity` is `info`, `warning`, or `error`.

`disposition` has one of four meanings:

- `preserved`: the Minecraft runtime retains the feature's behavior.
- `baked`: the editable feature was sampled or folded into emitted commands.
- `degraded`: a safe approximation or explicit fallback was used.
- `omitted`: the feature or affected events are absent from the output.

Diagnostics may include sorted `markerIds` and `trackIds`. Each array contains
at most 64 identifiers; `markerIdCount` and `trackIdCount` give the full unique
counts so consumers can detect truncation. The diagnostic vocabulary is
bounded by the exporter and never incorporates arbitrary project text into a
code, feature, severity, or disposition.

Report v1 covers timing and tempo maps, panning, fixed variants, gain and
automation, note-gate omission, pitch range, mute/solo filtering, Sound Stopper behavior, loops,
reference/custom audio, limiter omission, target/source/position fallbacks,
visualizer fallbacks, targets that predate Java data packs, and event-budget
truncation.

## Companion resource-pack report

When playable embedded Ogg/Vorbis assets are present, the export dialog can
write a separate Java resource-pack ZIP next to the data pack. It contains
`knead-resource-pack-report.json`, `pack.mcmeta`, isolated
`assets/<generated-namespace>/sounds.json` aliases, and only the referenced
audio bytes. It never writes `assets/minecraft/sounds.json` or converts arbitrary
project sound IDs into base-game paths.

The companion report uses schema version 1 and records the generated namespace,
resource-pack format, sound-event/variant/asset counts, total bytes, and the
same bounded diagnostics emitted by the data-pack report. Fixed variants use a
dedicated event alias; seeded deterministic variants are resolved per firing,
while the general alias retains weight metadata. WAV, MP3, Opus, malformed Ogg,
missing bytes, and unsafe paths are omitted with stable diagnostic codes rather
than being mislabeled as Java-compatible sounds.
